Cara running :

download file zip project, kemudian extract file project
buka file project dan klik kanan buka terminal cmd, kemudian ketik "npm run dev"
buka aplikasi xampp klik button start pada Apache dan MySQL, kemudian klik bagian admin pada MySql untuk membuka phpmyadmin. kemudian import database hingga berhasil.
buka file project di aplikasi VS Code, kemudian buka terminal VS Code ketik "php artisan serve" dan tekan 'enter'.
klik link http untuk live demo project
